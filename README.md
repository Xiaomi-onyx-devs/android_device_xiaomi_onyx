## ⚙️ Specifications

| Category | Details |
|:---------|:--------|
| **SoC** | Qualcomm SM8735 Snapdragon 8s Gen 4 (4 nm) |
| **CPU** | Octa-core (1×3.21 GHz Cortex-X4 + 3×3.0 GHz Cortex-A720 + 2×2.8 GHz Cortex-A720 + 2×2.0 GHz Cortex-A720) |
| **GPU** | Adreno 825 |
| **RAM** | 12 GB |
| **Storage** | 256 GB / 512 GB UFS 4.1 |
| **Display** | 6.67" AMOLED, 1280×2772 pixels, 19.5:9 ratio (~447 ppi) |
| **Battery** | 6500 mAh (International) / 7550 mAh Si/C Li-Ion (India) |
| **Rear Camera** | 50 MP, f/1.5, 26mm (wide), OIS + 8 MP, f/2.2, 15mm (ultrawide) |
| **Front Camera** | 20 MP, f/2.2 (wide) |
| **Dimensions** | 163.1 × 77.9 × 8.2 mm (6.42 × 3.07 × 0.32 in) |
| **Release Date** | June 24, 2025 |
| **Stock ROM** | Android 15, HyperOS 2 |
